# Rinda for Claude

Run [Rinda](https://rinda.ai) export sales from Claude — buyer lists, email campaigns and your inbox. Nothing is sent without your confirmation.

Claude에서 린다를 바로 쓰세요. 바이어 그룹·캠페인·받은메일을 대화로 다루고, 메일은 보내기 전에 꼭 한 번 더 확인을 받아요.

## Install · 설치

**Claude Code**

```
claude plugin marketplace add FINGU-GRINDA/rinda-plugin
claude plugin install rinda@rinda
```

Then run `/mcp`, pick **rinda** and sign in with your Rinda account.
설치한 뒤 `/mcp` 에서 **rinda** 를 골라 린다 계정으로 로그인하세요.

## What it can do · 할 수 있는 일

- Check what your workspace still needs and fill in your company profile
- Build buyer lists and draft email campaigns
- Start, pause and resume campaigns — after you confirm
- Read buyer replies, draft answers and send them — after you confirm

You need a Rinda account. Connecting a mailbox and billing are done in the Rinda web app.
린다 계정이 필요해요. 메일함 연결과 결제는 린다 웹에서 해요.
